# Working on Privateer

Privateer is a general Rust runtime for independent peers under a charter. Keep personal machine names, model preferences, credentials, endpoints, and fleet conventions in optional plugins and private configuration.

Complete authorized work without procedural permission loops. Preserve one recorded owner per outcome; allow departments to communicate and make routine decisions independently. Production deployment requires explicit authorization bound to an exact artifact and environment: a per-deployment approval, or a standing grant the captain created, with each deployment recorded against its artifact.

Prefer small modules, explicit argv/JSON protocols, transactional state changes, bounded queues and logs, and process identity checks. Never treat killing a wrapper as proof its payload stopped. Preserve durable facts when combining notifications.

Validate meaningful behavior: restart recovery, races, task custody, stale acknowledgments, provider route enforcement, resource admission, and real subprocess boundaries. Keep source and fixtures free of credentials. Run the tests relevant to a change and report the evidence and remaining limitations accurately.

The live First Mate/Corsair installations are not this repository's deployment target. Keep pilots isolated and reviewable. Do not claim full native agent autonomy from a scripted runtime pilot.
